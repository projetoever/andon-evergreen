# Modelos editoriais reutilizáveis do ANDON

Use [Padrão editorial M1](../PADRAO_EDITORIAL_M1.md) ao preparar qualquer PDF/DOCX. Os documentos aqui são **fontes Markdown**, não releases de software nem manuais homologados.

- [Modelo de manual](MODELO_MANUAL.md) — treinamento, operação e suporte.
- [Modelo de relatório](MODELO_RELATORIO.md) — gestão, produto, qualidade e entrega.

**Sequência:** copiar o modelo, preencher conteúdo real, vincular SHA, realizar revisão técnica, renderizar DOCX e PDF, inspecionar todas as páginas, colher aprovação e só então publicar na pasta oficial com hashes. Nenhuma seção com `[A DEFINIR]` pode constar em edição final sem justificar pendência.
