# REFINE 12 — R12-04H2 | Inventário cadastral global seguro, sem ampliar consulta operacional

Data: 10/11/2026. Base PR #414 R12-04H1 → #412 G2 → #410 G1 → #408 tipos → #406 subconjuntos → #404 conjuntos → E034 #385.

## Problema confirmado
A aba Máquinas usava `useAndon().machines`, derivado de `GET /api/machines`, que é corretamente filtrado por `machineScope` e inclui campos sensíveis de operação: status, chamado atual, prioridade, eventos de produção. Permitir que um perfil Produção/Manutenção/gerente com `andon.settings.open` visualizasse esse endpoint inteiro para todas as máquinas violaria a segregação operacional do Hub.

## Solução
- Nova rota exclusiva `GET /api/andon-settings/machines`, protegida por flag **independente, OFF por padrão** `ANDON_CENTRAL_MACHINE_INVENTORY_HTTP_ENABLED=1`, com sessão humana Hub normal, workstation ativa/aprovada, HTTPS, Origin e `andon.read` + `andon.settings.open` ou Admin principal full-scope. Acesso selected permite catálogo **apenas**; não altera `machineScope`.
- Resposta estrita com `{items:[{id,name,requireWorkOrderAtOpen,isActive}],nextCursor}`. Não retorna `machineStatus`, `andonStatus`, `currentCallId`, `productionEvents`, `failureEvents`, `priorityOrder`, timestamps de intervenções, responsáveis, notas ou credenciais. Paginação estável por ID, lote padrão 100, limite máximo 200, allowlist de filtros (`cursor`, `limit`), cabeçalho `Cache-Control: no-store`. Sem endpoint de escrita próprio.
- Autorização central por requisição, sem identidade de serviço e sem exceção via IP. Revalidação de sessão/permissões, workstation e flag após locks transacionais usuário→workstation, antes de buscar todos os metadados.
- Integrada em seção **Inventário cadastral global** na aba Máquinas somente em modo central. Traz a listagem saneada, carregamento progressivo, edição **somente** de nome e exigência de OS, usando `PATCH /api/machines/:id` existente (guardado por `ANDON_CENTRAL_MACHINE_SETTINGS_HTTP_ENABLED=1`, também OFF). Ao editar outra máquina fora de `machineScope`, a resposta agora também é saneada aos mesmos quatro campos: antes, o retorno completo `machineSelect` poderia revelar status, chamado e eventos de produção mesmo após uma edição de cadastro autorizada. Para uma máquina já dentro do `machineScope`, a resposta operacional legada continua completa para compatibilidade com o repositório do ANDON. A API não confere ao editor alterações físicas.
- Quando a flag está OFF, exibe indisponibilidade controlada, sem utilizar `GET /api/machines` como atalho para a lista global. O painel operacional existente continua filtrado pelo `machineScope` e a UI central de produção/ativação segue desabilitada (H1). Todos os rótulos UI novos têm PT/EN/ZH tradicional.
